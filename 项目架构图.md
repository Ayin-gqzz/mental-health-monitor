## 二、泳道图（系统交互流程）

### 2.1 用户登录流程

```mermaid
sequenceDiagram
    actor User as 用户
    participant FE as 前端<br/>React + Zustand
    participant API as 后端 API<br/>FastAPI
    participant DB as 数据库<br/>MySQL/SQLite

    User->>FE: 输入用户名/密码，选择角色
    FE->>FE: 表单校验

    alt 学生登录
        FE->>API: POST /api/auth/login<br/>{student_id, password}
        API->>DB: SELECT * FROM student_info<br/>WHERE student_id = ?
        DB-->>API: 学生记录
        API->>API: bcrypt 验证密码
        API->>API: 生成 JWT Token<br/>{role:"student", user_id, department}
        API-->>FE: {access_token, role, display_name}
    else 辅导员/管理员登录
        FE->>API: POST /api/auth/login/counselor<br/>{username, password}
        API->>DB: SELECT * FROM counselor_user<br/>WHERE username = ?
        DB-->>API: 辅导员记录
        API->>API: bcrypt 验证密码
        API->>API: 生成 JWT Token<br/>{role:"counselor", department, is_admin}
        API-->>FE: {access_token, role, display_name, is_admin}

        alt 角色与身份不匹配
            FE->>FE: 提示"该账号是管理员/辅导员"<br/>拒绝登录
        end
    end

    FE->>FE: setAuth() 存储到 Zustand + localStorage
    FE->>FE: navigate 到对应角色首页
```

### 2.2 学生提交每周测评 + NLP 分析流程

```mermaid
sequenceDiagram
    actor Student as 学生
    participant FE as 前端
    participant API as 后端 API
    participant NLP as NLP 引擎<br/>PsychAssessmentEngine
    participant LLM as LLM 服务<br/>OpenAI-compatible
    participant DB as 数据库

    Student->>FE: 填写五维评分 + 留言
    FE->>FE: 计算加权总分<br/>情绪25%+睡眠20%+学业20%+社交15%+生活20%

    FE->>API: POST /api/student/weekly-assessments<br/>{mood, sleep, study, social, life, message}
    API->>API: 校验本周是否已提交

    alt 有留言文本
        API->>NLP: full_analysis(message)
        NLP->>NLP: 文本清洗(正则去噪)
        NLP->>NLP: Jieba 分词 + 去停用词
        NLP->>NLP: 情感词典匹配(74正面+100负面词)<br/>加权求和 → 情感得分 0-1
        NLP->>NLP: TF-IDF 关键词提取
        NLP->>NLP: 8类心理话题分类<br/>(学业压力/人际关系/情感问题等)
        NLP-->>API: {sentiment_score, keywords, topics}

        API->>LLM: 生成 AI 回复(异步)
        LLM-->>API: AI 回复文本
    end

    API->>DB: INSERT INTO weekly_assessment<br/>(student_id, scores, message, sentiment, ai_reply)
    DB-->>API: OK
    API-->>FE: 提交成功
    FE-->>Student: 显示成功提示
```

### 2.3 辅导员查看群体画像 + 聚类分析流程

```mermaid
sequenceDiagram
    actor Counselor as 辅导员/管理员
    participant FE as 前端<br/>ClusterAnalysisPage
    participant API as 后端 API<br/>/cluster-analysis
    participant Cache as 内存缓存<br/>按院系隔离
    participant DB as 数据库<br/>student_latest_stats
    participant ML as scikit-learn<br/>MiniBatchKMeans

    Counselor->>FE: 进入群体画像页面

    FE->>API: GET /api/counselor/cluster-analysis
    API->>Cache: 检查缓存(10分钟TTL)

    alt 缓存命中
        Cache-->>API: 返回缓存数据
    else 缓存未命中
        API->>API: _ensure_once()<br/>检查预聚合表是否为空

        alt 预聚合表为空
            API->>DB: 执行 refresh_weekly_stats<br/>预聚合 10万行数据
        end

        alt 普通辅导员
            API->>DB: SELECT * FROM student_latest_stats<br/>WHERE department = :dept
        else 管理员
            API->>DB: SELECT * FROM student_latest_stats<br/>(全量 10万行)
        end
        DB-->>API: 行为数据行

        API->>ML: StandardScaler 标准化
        API->>ML: MiniBatchKMeans(k=4, batch=2048)<br/>聚类 → 4个群体
        API->>ML: PCA(n_components=2) 降维
        API->>API: 生成 16 种群体画像<br/>(名称+特征描述+干预建议)
        API->>Cache: 写入缓存
    end

    API-->>FE: {clusters, scatter, global_means}

    par 前端渲染五种图表
        FE->>FE: PCA 散点图(ScatterChart)
        FE->>FE: 雷达图(RadarChart)
        FE->>FE: 风险分布柱状图(BarChart)
        FE->>FE: 特征对比表格
        FE->>FE: 群体解读卡片(traits+suggestions)
    end
```

### 2.4 ML 模型训练与批量评估流程

```mermaid
sequenceDiagram
    actor Dev as 开发者/Docker
    participant Train as ml/train.py
    participant CSV as 数据集.csv<br/>10万条
    participant SK as scikit-learn
    participant Pkl as 模型文件<br/>6个 .pkl
    participant Assess as scripts/assess_all.py
    participant ML_Svc as MLService<br/>(单例)
    participant DB as 数据库

    Dev->>Train: 启动训练

    Train->>CSV: 加载数据集(10万行)
    Train->>Train: 80/20 分层划分<br/>train/test
    Train->>Train: 特征工程(16个特征)<br/>性别编码+院系OneHot<br/>+压力变化率+睡眠质量指数<br/>+生活方式综合分
    Train->>SK: StandardScaler.fit(train)

    Train->>SK: GridSearchCV<br/>RF(n_estimators,max_depth,...)<br/>3折分层CV, 评分=ROC-AUC
    SK-->>Train: 最优超参数

    Train->>SK: model.predict_proba(test)
    Train->>Train: Youden's J 找最优阈值<br/>max(TPR - FPR)
    Train->>Pkl: 保存 6 个 pkl 文件<br/>(model,scaler,features,threshold,metadata,curves)

    Note over Train,DB: 训练完成，开始批量评估

    Dev->>Assess: 启动批量评估
    Assess->>DB: SELECT with ROW_NUMBER()<br/>取每个学生最新行为记录
    DB-->>Assess: 10万行数据

    loop 每个学生
        Assess->>ML_Svc: predict(profile, behavior)
        ML_Svc->>ML_Svc: 特征工程(同训练)
        ML_Svc->>ML_Svc: model.predict_proba
        ML_Svc->>ML_Svc: risk_level =<br/>high(预测抑郁 OR stress≥8)<br/>medium(stress≥6) / low
        ML_Svc-->>Assess: {depression, probability, risk}
    end

    Assess->>DB: 批量 INSERT mental_assessment<br/>(每5000条一批)
    Assess->>DB: 视图/触发器自动写入<br/>risk_notification
```

### 2.5 统计检验流程（T检验/卡方/相关性）

```mermaid
sequenceDiagram
    actor Counselor as 辅导员
    participant FE as 前端<br/>StatAnalysisPage
    participant API as 后端 API
    participant Cache as 缓存(30分钟TTL)
    participant DB as student_latest_stats
    participant SciPy as scipy/numpy

    Counselor->>FE: 进入统计检验页面

    par 三个接口并行请求
        FE->>API: GET /statistics/t-test
        FE->>API: GET /statistics/chi-square
        FE->>API: GET /statistics/correlation
    end

    Note over API: 三个端点共享 _get_stat_base()
    API->>Cache: 检查缓存(带线程锁)
    alt 缓存命中
        Cache-->>API: 返回缓存
    else 缓存未命中(只有第一个请求查库)
        API->>DB: SELECT 10万行 → 缓存
    end

    par T检验
        API->>SciPy: numpy 数组切片<br/>高风险组 vs 低风险组
        API->>SciPy: ttest_ind(g1, g2)<br/>5个指标各做一次
        SciPy-->>API: t统计量 + p值
    and 卡方检验
        API->>SciPy: 向量化构建列联表<br/>性别×抑郁 2×2
        API->>SciPy: chi2_contingency(table)
        SciPy-->>API: χ² + p值 + 自由度
    and 相关性分析
        API->>SciPy: numpy.corrcoef → Pearson r
        API->>SciPy: rankdata + corrcoef → Spearman r
        API->>SciPy: 手动计算 p值(t分布)
        SciPy-->>API: 3变量×2方法 = 6个结果
    end

    API-->>FE: 三组结果并行返回
    FE->>FE: 渲染表格 + 柱状图
```

### 2.6 预警触发与辅导员干预流程

```mermaid
sequenceDiagram
```
